# Roadtrip

Static road trip landing page for the San Diego to Jackson 2026 family trip.

## Local preview

Open `index.html` directly in a browser, or run a simple local server from the repo root:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

This repository is set up as a simple static site. To publish it with GitHub Pages:

1. Push the contents of this repository to GitHub.
2. In the GitHub repository, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and the `/ (root)` folder.
5. Save the settings and wait for GitHub Pages to publish the site.

Once enabled, the page will be served from the repository's GitHub Pages URL.
